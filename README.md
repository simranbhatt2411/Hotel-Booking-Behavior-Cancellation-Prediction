# Booking Behavior & Cancellation Analysis
### Python + SQL + Excel Analytics Project

## Overview
End-to-end analysis of 500+ hotel booking records sourced from Kaggle to uncover 
cancellation patterns, customer behavior, and booking trends. The project helps 
stakeholders understand cancellation drivers and improve forecasting and 
operational planning.

## Tools & Technologies
SQL | Python | Pandas | NumPy | Plotly | Excel | Jupyter Notebook

## Dataset
- **Source:** Kaggle
- **Size:** 500+ records
- **Features:** Booking ID, Hotel Type, Lead Time, Deposit Type, 
  Customer Type, Special Requests, Cancellation Status

## Key Objectives
- Analyze factors contributing to hotel booking cancellations
- Compare cancellation rates between city and resort hotels
- Explore customer booking behavior and lead times
- Identify correlations between cancellations and deposit type, 
  customer type, and special requests
- Visualize insights with interactive Plotly dashboards

## Key Findings
- Identified top cancellation drivers across hotel types
- Compared city vs resort hotel cancellation patterns
- Analyzed impact of lead time and deposit type on cancellation rate

## Files Included
- `Hotel_Cancellation.ipynb` — Jupyter Notebook with full analysis
- `SQL_Queries.sql` — Data extraction queries
- `Dashboard.xlsx` — Excel dashboard
- `README.md` — Project documentation

## How to Use
1. Open `Hotel_Cancellation.ipynb` in Jupyter Notebook
2. Run cells sequentially to reproduce the analysis
3. Open `Dashboard.xlsx` in Excel to explore the dashboard
